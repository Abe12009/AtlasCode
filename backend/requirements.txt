# Pinned explicitly because nothing here asks for a particular `pyasn1`: it
# arrives transitively behind loose floors, from python-jose
# (`pyasn1>=0.5.0`) and from `rsa` (`pyasn1>=0.1.3`), so unpinned the
# resolved version is just whatever the resolver lands on.
#
# 0.6.5 over 0.6.4 for four quadratic-CPU DoS advisories in the ASN.1
# decoder: CVE-2026-119194 (a container of many distinct long tag IDs),
# CVE-2026-119195 (many-fragment constructed OCTET/character STRING, plus
# the indefinite-length `ANY` path), CVE-2026-119196 (constructed BIT STRING
# re-shifting the accumulated value per fragment) and CVE-2026-119197

# a fix exists and the bump is free, not because any of it is reachable

# pure-Python RSA fallback, and the [cryptography] extra makes
# jose.backends.cryptography_backend the active one for both RSA and EC, so
# rsa_backend never loads and `pyasn1` never gets imported -- checked by
# exercising both jose call sites this app has (app/core/security.py on
# HS256, app/services/firebase_auth.py on RS256). Keep the pin so the floor
# can't drift back down under a future jose or rsa.
